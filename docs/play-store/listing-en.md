# Play Store listing (EN)

**App title (max 30):** Lauschig

## Short description (max 80)

Offline-first audiobook player for your own audiobook server.

## Full description (max 4000)

Lauschig is a fast, calm audiobook player for Audiobookshelf servers, built for listening first.

Your library and downloaded books open instantly. Lauschig never waits for the network at startup: the library comes from the local database, and anything you downloaded plays right away, even in airplane mode, with an expired login, or when your server is unreachable.

Features
- Offline first: library, covers and progress are stored on your device
- Download whole books and listen without a connection
- Progress sync with your server: the most recent position wins, and time listened offline is uploaded later
- "Back to hh:mm:ss" if another device moved your position a long way
- Local and public server address: Lauschig falls back to the public address automatically and stays quietly offline otherwise
- Chapters, sleep timer and playback speed
- Home, Library, Discover and Search tabs
- Tokens stored encrypted on the device
- No ads, no analytics, no tracking, no account with the developer

Lauschig connects only to the server you enter. You need your own Audiobookshelf server (version 2.x) to use it.

Lauschig is open source (GPL-3.0-or-later): https://github.com/Detair/lauschig
